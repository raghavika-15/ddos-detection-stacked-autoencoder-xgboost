\# DDoS Attack Detection Using Stacked Autoencoders and XGBoost



\## Overview



This project presents a hybrid deep learning and machine learning approach for detecting Distributed Denial-of-Service (DDoS) attacks. The system uses Stacked Autoencoders for feature extraction and dimensionality reduction, followed by XGBoost for attack classification.



\## Features



\* Data preprocessing and cleaning

\* Feature selection using Genetic Algorithms

\* Stacked Autoencoder-based feature learning

\* XGBoost classifier for attack detection

\* Model evaluation and performance analysis



\## Dataset



The project uses the CIC-DDoS2019 dataset.



Dataset source:

https://www.unb.ca/cic/datasets/ddos-2019.html



Note: Large dataset files are not included in this repository.

\## Objective



To improve DDoS attack detection accuracy by combining deep feature extraction through stacked autoencoders with the classification power of XGBoost.
